# Changelog

All notable changes to habitloop are documented here. The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-26

### Added

- Installable PWA: web app manifest, PNG + maskable icons (generated by `npm run icons`) and an apple-touch icon.
- Offline support: a service worker generated at build time by a small Vite plugin (`plugins/service-worker.ts`) precaches the whole build; navigations are network-first with the cached app shell as fallback, and old caches are removed on update.
- Keyboard shortcuts: `N` new habit, `1`–`9` check off a habit, `T` / `I` switch views, `?` shortcuts dialog, `Esc` close / back. Shortcuts are ignored while typing in a field.
- GitHub Actions CI (lint, typecheck, tests, build on Node 22 and 24) and a GitHub Pages deploy workflow.

### Fixed

- Stored data that cannot be read (corrupt JSON or data from a newer version) is now copied to `habitloop:unreadable` before the app saves, instead of being overwritten.

## [0.3.0] - 2026-10-25

### Added

- Insights tab: completion rates for the last 7 / 30 days and all time, total check-ins, active days, top streak, check-ins by weekday chart and a per-habit table.
- Weekly goals (1–6× per week) with streaks counted in weeks.
- JSON backup export and validated import (merge or replace).
- Storage schema v2 with automatic migration from v1 (`habitloop:v1` → `habitloop`).

## [0.2.0] - 2026-10-23

### Added

- GitHub-style year heatmap, combined on the home screen and per habit.
- Habit detail view with stats and history; edit name and color; archive / restore; reorder habits.

## [0.1.0] - 2026-10-22

### Added

- Core tracker: add habits with a color, one-tap daily check-in, 7-day strip, current / best streaks, daily progress bar, delete with confirmation, validated `localStorage` persistence.
